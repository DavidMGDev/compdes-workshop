Cómo usar su llave API

Parte 1 — Hora 1: Construir Distribuidora Central
Taller de Seguridad de Agentes MCP/RAG · COMPDES 2026

Su llave tiene presupuesto limitado. Cada asistente dispone de aproximadamente US$1.10. El presupuesto se comparte entre los 5 integrantes de su grupo (US$5.50 por grupo). Si un integrante consume de más, afecta a los otros cuatro. El modelo ya viene fijado en el económico; solo evite bucles infinitos.

1Reciba y guarde su llave

El tutor le entregará una llave con este formato:

AQ.Ab8RN6xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx

Es una llave moderna de Google AI Studio (empieza con AQ.) y está restringida: solo funciona con la API de Gemini. No sirve para ningún otro servicio de Google.

No la publique. No la suba a GitHub, no la pegue en capturas de pantalla, no la comparta en el chat del evento. Si la expone, avísele al tutor para revocarla.

2Colóquela en el archivo .env

En la raíz de su laboratorio (~/compdes-lab), cree o edite el archivo .env:

OPENAI_BASE_URL=https://generativelanguage.googleapis.com/v1beta/openai/
OPENAI_API_KEY=AQ.Ab8RN6...su-llave-aquí
AGENT_MODEL=gemini-3.5-flash-lite

POSTGRES_USER=onyx_app
POSTGRES_PASSWORD=app_password_123
POSTGRES_DB=distribuidora
POSTGRES_HOST=localhost
POSTGRES_PORT=5433

Usamos el endpoint compatible con OpenAI de Google. Así todo el código del taller funciona sin cambios: solo cambian esas tres primeras variables.

El modelo ya está fijado

Todo el taller usa un único modelo: gemini-3.5-flash-lite ($0.30 entrada / $2.50 salida por 1M tokens). Es el modelo 3.5-class más económico de Google y está afinado para flujos con herramientas, que es justo lo que hace este agente. No hay que elegir nada: ya viene puesto en el .env.

Nota. El manual original mencionaba gemini-3-flash; ese identificador no existe (da error 404). Está reemplazado en todas partes por gemini-3.5-flash-lite.

3Compruebe que la llave funciona

Antes de construir nada, confirme que su llave responde. Elija una opción:

Opción A — desde la terminal (curl)

curl https://generativelanguage.googleapis.com/v1beta/openai/chat/completions \
  -H "Authorization: Bearer $OPENAI_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gemini-3.5-flash-lite",
    "messages": [{"role": "user", "content": "Responde solo: listo"}]
  }'

Opción B — desde Python

import os
from openai import OpenAI

client = OpenAI(
    base_url=os.environ["OPENAI_BASE_URL"],
    api_key=os.environ["OPENAI_API_KEY"],
)

resp = client.chat.completions.create(
    model=os.environ["AGENT_MODEL"],
    messages=[{"role": "user", "content": "Responde solo: listo"}],
)
print(resp.choices[0].message.content)

Resultado esperado: el modelo responde listo. Si lo ve, su llave está operativa y puede continuar.

Si algo falla

ErrorSignificadoQué hacer
401 UNAUTHENTICATED La llave está mal copiada o incompleta. Cópiela de nuevo, completa, sin espacios ni saltos de línea.
429 RESOURCE_EXHAUSTED
«prepayment credits are depleted»		 Se agotó el presupuesto del grupo. Avise al tutor. No es culpa de su código.
429 por límite de tasa Demasiadas peticiones por minuto. Espere unos segundos y reintente.
404 modelo no encontrado Identificador de modelo incorrecto. Confirme que AGENT_MODEL es gemini-3.5-flash-lite en el .env.

4Use la llave en Onyx Lite (vitrina 1A)

Tras instalar Onyx Lite y abrir http://localhost:3000:

  1. Vaya a Settings → LLM.
  2. Agregue un proveedor de tipo OpenAI-compatible (no «Google», porque usamos el endpoint compatible).
  3. Complete los campos:
    • Base URL: https://generativelanguage.googleapis.com/v1beta/openai/
    • API Key: su llave AQ.Ab8RN6...
    • Model name: gemini-3.5-flash-lite
  4. Guarde y lance la pregunta de negocio del manual:
    «¿Cuál es el plazo máximo de crédito que podemos otorgar a un cliente nuevo según nuestra política?»

El agente debe responder citando el PDF que usted ingirió. Ese es el gancho de la Hora 1.

5Use la llave en el objetivo controlable (1B)

El agente en Python lee las variables del .env. Cárguelas antes de ejecutarlo:

# Linux / macOS
set -a && source ~/compdes-lab/.env && set +a

# Windows PowerShell
Get-Content "$HOME\compdes-lab\.env" | ForEach-Object {
  if ($_ -match '^\s*([^#][^=]*)=(.*)$') {
    [Environment]::SetEnvironmentVariable($Matches[1].Trim(), $Matches[2].Trim(), "Process")
  }
}

Verifique que quedaron cargadas:

# Linux / macOS
echo $AGENT_MODEL

# Windows PowerShell
$env:AGENT_MODEL

Debe imprimir gemini-3.5-flash-lite. Con eso, el agente del apartado 1B ya puede arrancar.

6Cuide su presupuesto

  • No deje bucles corriendo. Un while sin freno agota los US$5.50 del grupo en minutos.
  • Historiales cortos. Cada mensaje reenvía toda la conversación; si crece, cada llamada cuesta más.
  • Pruebe con flash-lite. Cambie a un modelo caro solo cuando el flujo ya funcione.
  • El corte es automático. Al agotarse el crédito, la llave deja de responder con error 429. No hay cargos sorpresa.

Fin de la Parte 1. Al llegar aquí usted debe tener: la llave verificada, Onyx Lite respondiendo con citas de sus PDFs, y el objetivo controlable listo para atacar en la Hora 2.
